## 🚀 Funcionalidades
* **Listagem Dinâmica:** Consulta de produtos direto da API pública DummyJSON.
* **Pesquisa:** Barra de busca em tempo real por nome de produto.
* **Detalhes do Produto:** Exibição de informações completas (descrição, categoria, preço, avaliação) em janela modal.
* **Sistema de Favoritos:** Adição e remoção de produtos favoritos salvos de forma persistente utilizando o localStorage do navegador.
* **Tratamento de Erros e Carregamento:** Avisos visuais em caso de falha de requisição ou carregamento de dados.

## 🛠️ Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 (Responsivo com Grid e Flexbox)
* JavaScript Moderno (ES6+, Fetch API, Async/Await, DOM manipulation, JSON)

## 💻 Como Executar
1. Clone ou baixe este repositório para o seu computador.
2. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estão na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` ou abra-o utilizando um navegador web moderno (Chrome, Edge, Firefox).
